# 🚚 Zap Shift

Zap Shift is a parcel delivery management web application that helps users send and track parcels while allowing admins and delivery riders to manage the complete delivery process.

## 🌐 Live Website

[Live Demo](https://zap-shift-client1.onrender.com/)

## 🔗 Server

[Server API](https://zap-shift-server-sd3r.onrender.com/)

## ✨ Features

- User authentication with Firebase
- Parcel payment with Stripe
- Parcel tracking
- Delivery rider management
- Admin dashboard
- Rider dashboard
- Parcel assignment system
- Delivery status management
- Bangladesh district and upazila selection
- Responsive design
- Secure API requests
- MongoDB database
- Real-time delivery status updates

## 👥 User Roles

### User

Users can:

- Create an account
- View their parcels
- Make payments
- Track parcels
- View delivery status

### Rider

Riders can:

- View assigned deliveries
- Accept or reject delivery requests
- Update delivery status
- View delivery history
- See delivery statistics

### Admin

Admins can:

- Manage users
- Manage riders
- Approve riders
- Assign riders to parcels
- Monitor parcel delivery
- View dashboard statistics

## 📦 Parcel Delivery Flow

```text
User
  ↓
Create Parcel
  ↓
Payment
  ↓
Admin Assigns Rider
  ↓
Rider Accepts Delivery
  ↓
Pick Up Parcel
  ↓
Parcel In Transit
  ↓
Parcel Delivered
```
